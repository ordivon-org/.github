# Ordivon

Ordivon develops agent-native computing, research, media, world interaction, games, human research, and security infrastructure in the open by default.

Public repositories are intended to expose source code, tests, reproducible research artifacts, design records, and verification evidence when those materials can be shared lawfully and without leaking sensitive reality. Private or embargoed carriers are exceptions for secrets, raw or linkable personal data, third-party restricted material, responsible-disclosure security work, patent-sensitive inventions before a publication decision, and operational state that would create unnecessary risk.

Unless a repository states otherwise in its own `LICENSE`, Ordivon software is released under the Apache License 2.0. Repository visibility, copyright ownership, patent rights, trademark rights, and contribution provenance are separate questions and are handled explicitly.

See [PUBLICATION_POLICY.md](../PUBLICATION_POLICY.md), [CONTRIBUTING.md](../CONTRIBUTING.md), [SECURITY.md](../SECURITY.md), and [TRADEMARKS.md](../TRADEMARKS.md).
